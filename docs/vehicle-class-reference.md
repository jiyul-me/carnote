# 차종 분류·비승용 세율 참고 (2026-08 조사)

승용 외 차종을 다룰지 결정할 때 쓰는 자료. **아직 사이트에 구현하지 않았다** — 현재는 승용만 페이지를 만들고 비승용은 `vehicleClass`로 제외한다.

## 분류 기준 (자동차관리법 제3조)

- **승용** 10인 이하 / **승합** 11인 이상
- 정원과 무관하게 승합으로 보는 예외 3가지: ① 내부 특수설비로 정원이 10인 이하가 된 차(구급차·헌혈차 등) ② 경형 전방조종자동차 ③ 캠핑용자동차
- **화물**: 화물적재공간(바닥면적 2㎡ 이상)을 갖추고, 적재화물 무게 > 승객 무게

**9인승은 승용이다.** "9인승=승합" 통설은 개별소비세법(정원 8인 이하만 과세)과의 혼동.
근거: 도로교통법 시행령 별표1이 "9인승 이상 **승용자동차** 및 승합자동차"로 규정 / 현대차 공식 가격표는 11인승에만 110km/h 속도제한, 라운지 7인승에만 개소세 과세 표기 / 서울행정법원 판결(7~10인승 승용 과세 적법).
※ 견적사이트(카눈)의 "차종: 승합" 표기는 법정 차종이 아니라 차체 세그먼트 라벨이므로 근거로 쓰지 말 것.

## 비승용 세율 (지방세법 제127조, 비영업용)

**승합** — 지방교육세·차령 경감 없음
| 구분 | 영업용 | 비영업용 |
|---|---|---|
| 소형일반버스 | 25,000원 | **65,000원** |
| 대형일반버스 | 42,000원 | 115,000원 |

대형 기준은 정원 36인 이상 **또는 길이 9m 이상**. 카니발·스타리아 11인승(5.2m)은 자동차관리법상 중형승합이지만 세법상 **소형일반버스 = 65,000원**.

**화물** — 적재정량 기준, 지방교육세 없음
| 적재정량 | 영업용 | 비영업용 |
|---|---|---|
| 1,000kg 이하 | 6,600원 | **28,500원** |
| 2,000kg 이하 | 9,600원 | 34,500원 |
| 3,000kg 이하 | 13,500원 | 48,000원 |
| 4,000kg 이하 | 18,000원 | 63,000원 |
| 5,000kg 이하 | 22,500원 | 79,500원 |
| 8,000kg 이하 | 36,000원 | 130,500원 |
| 10,000kg 이하 | 45,000원 | 157,500원 |

1만kg 초과분은 1만kg마다 영업용 1만원·비영업용 3만원 가산.

## 경과규정·특례

- **2001년 이전 등록분**: 구기준(승용 6인 이하 / 승합 7~12인)이 폐차까지 유지 → 1세대 카니발·스타렉스 9인승 등은 지금도 승합. 세율은 2005년 33% → 2006년 66% → 2007년 100%로 단계 인상됐다.
- **지방세특례제한법 제67조 3항**(7~10인승에 65,000원): 시행규칙이 대상을 **전방조종자동차**(스타렉스·그레이스 등 원박스형)로 한정 → **SUV·미니밴은 해당 없음**. 싼타페·쏘렌토 7인승은 배기량 과세.
- 승합으로 최초 등록된 차는 좌석을 10인 이하로 구조변경해도 승합 세율 유지(지방세운영과-120).
- 승용 SUV의 뒷좌석을 떼도 화물차로 **차종 변경은 불가**(시행규칙 제55조 3호 — 차종 변경 튜닝은 승인 대상 아님).

## 사이트 데이터 관련 확인 사항

- **현재 제외 중(truck)**: 포터2 2종·봉고3 2종
- **추가하면 안 되는 차종**: 렉스턴 스포츠/칸(픽업=화물), 스타리아 카고(화물), 스타리아 캠퍼(캠핑카=승합)
- **쏘렌토·싼타페는 국내에 밴/화물 사양이 없었다** — 7인승이 많았던 건 2000년까지 7~10인승이 승합(65,000원)이었기 때문이고, 승합 혜택 종료 직후인 2007년에 쏘렌토 5인승이 추가됐다. 쏘렌토 기반 픽업(BL SUT)은 2002년 검토됐으나 미출시.
- 밴(화물)이 실재했던 국산 SUV: 무쏘·코란도·코란도 훼미리·갤로퍼·스포티지 1세대·레토나·카니발 1세대 6인승 — 전부 프레임 바디 계열로, 모노코크 도심형 SUV는 화물 구조 요건을 못 맞춘다.
