1. 수집하는 개인정보가 없습니다

카노트는 회원가입이 없으며, 이용자가 입력한 차량 정보·정비 기록·주유 기록 등 모든 데이터는 이용자의 브라우저(localStorage)에만 저장됩니다. 이 데이터는 카노트 서버로 전송되지 않으며, 운영자는 이를 열람할 수 없습니다. (카노트는 별도의 데이터 수집 서버를 두지 않은 정적 웹사이트입니다.)

"JSON으로 내보내기" 기능으로 만들어지는 백업 파일은 이용자 기기에 저장되며, 그 보관·관리 책임은 이용자에게 있습니다.

2. 호스팅 과정에서 처리되는 정보

본 사이트는 GitHub Pages에서 호스팅됩니다. 호스팅 사업자는 서비스 제공·보안을 위해 접속 IP 주소 등 표준 웹 로그를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요.

3. 쿠키 및 광고

현재 카노트는 쿠키를 사용하지 않습니다. 향후 서비스 운영을 위해 광고(구글 애드센스) 또는 제휴 링크(쿠팡파트너스)가 도입되는 경우, 광고 제공 과정에서 제3자(구글 등)가 쿠키를 사용할 수 있습니다. 도입 시 이 방침을 갱신해 고지하며, 구글의 광고 쿠키에 대한 자세한 내용과 수신 거부 방법은 구글 광고 정책에서 확인할 수 있습니다.

4. 이용자의 권리

모든 데이터가 이용자 기기에 있으므로, 삭제를 원하시면 수첩의 "전체 데이터 삭제" 기능을 사용하거나 브라우저의 사이트 데이터 삭제 기능을 이용하면 즉시·완전히 삭제됩니다.

5. 문의

본 방침에 관한 문의는 GitHub 저장소 이슈로 남겨주세요.

본 방침은 서비스 변경에 따라 갱신될 수 있으며, 변경 시 이 페이지에 게시합니다.
